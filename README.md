# ClickFlow – Updates

Dieses Repo enthält nur die veröffentlichten Versionen von ClickFlow.

- **ClickFlow-Setup.exe** – Installer der aktuellen Version (installiert ohne Adminrechte)
- **latest.txt** – Versionsinfo, die ClickFlow beim Start liest (Version, Download, SHA-256)

Neu installieren: `ClickFlow-Setup.exe` herunterladen und ausführen. Installierte Versionen aktualisieren sich selbst.
